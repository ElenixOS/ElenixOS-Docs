# Display Service

The display service coordinates brightness and screen power state. The platform display port performs the actual operations, while the service manages system requests and their effects.

Brightness values range from 0–100. Brightness changes can take effect immediately or use preset transition durations; temporary brightness preserves the previous value for the system to restore. Display power control is used to wake or turn off the screen, and applications should not bypass power management policies to directly operate the platform port.

Display Service synchronously calls device brightness operations and maintains the requested value; the brightness operation in the device table is required, while power on/off is optional and currently has no physical completion callback. The LVGL framebuffer, refresh, and input devices are provided by the platform graphics HAL and are not part of the brightness/power operation table. An application observing brightness state does not equate to device confirmation. See [Application Contract](../../application_contract) and [Platform/Vendor Contract](../../platform_contract).
