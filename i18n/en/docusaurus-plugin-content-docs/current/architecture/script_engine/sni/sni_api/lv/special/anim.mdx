# Animation

`lv.anim` is a script-configurable LVGL animation object:

```js
const anim = new lv.anim();
anim.init();
anim.setVar(obj);
anim.setValues(0, 100);
anim.setDuration(300);
anim.setCustomExecCb((_anim, value) => obj.setX(value));
anim.setPathCb(anim.pathEaseInOut());
anim.start();
```

After construction, `init()` must be called before setting the variable and other parameters. The current binding provides methods for animation initialization, variable, duration/delay, start/end values, custom execution callback, path callback, ready/delete callbacks, play, repeat, and `start`; path functions are provided as instance methods such as `pathLinear`, `pathEaseIn`, `pathEaseOut`, `pathEaseInOut`, and return built-in path values that can be passed to `setPathCb`. The custom execution callback receives `(anim, value)`, and typically operates on the object to be updated through a closure. The global `lv.anim_path_ease_in_out` and `setExecCb` in the old examples are not the current interface names.

Animation callbacks execute in the LVGL main loop. After the Activity/View or the script context to which the animation belongs is destroyed, the animation handle becomes invalid; when the application is suspended, Recent Apps continues or jumps to the end state according to the animation resume policy.
