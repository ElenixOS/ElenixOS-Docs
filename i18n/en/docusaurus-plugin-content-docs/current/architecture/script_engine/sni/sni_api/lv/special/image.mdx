`lv.image` is used to display image resources:

```js
const image = new lv.image(eos.view.active());
image.setSrc("/path/to/image.png");
image.setScale(256);
```

The current binding provides interfaces such as `setSrc`, offset, rotation, pivot, scaling, blend mode, anti-aliasing, and internal alignment, as well as the corresponding read properties. The image source must be a resource path or data supported by the current port; path access is still subject to script package/storage boundaries. `setOpacity` is not a current `lv.image` method; object style interfaces should be used to set transparency.
