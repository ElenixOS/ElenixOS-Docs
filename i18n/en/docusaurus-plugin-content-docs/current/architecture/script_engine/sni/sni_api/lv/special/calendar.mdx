# Calendar

```js
const calendar = new lv.calendar(eos.view.active());
calendar.setTodayDate(2026, 9, 1);
calendar.setShowedDate(2026, 9);
const dates = [{year: 2026, month: 9, day: 5}];
calendar.setHighlightedDates(dates, dates.length);
```

The current bindings use `setTodayDate`, `setShowedDate`, `setHighlightedDates`, `setDayNames`, and `getBtnmatrix`, and provide the corresponding properties. The older `setDate`, `setMarkedDates`, and `getDate` are not part of the currently exported calendar method names.
