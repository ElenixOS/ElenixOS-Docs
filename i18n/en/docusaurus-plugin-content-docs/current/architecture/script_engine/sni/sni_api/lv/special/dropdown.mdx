# Dropdown

```js
const dropdown = new lv.dropdown(eos.view.active());
dropdown.setOptions("Item 1\nItem 2");
dropdown.setSelected(0);
dropdown.addEventCb(() => {
    eos.console.log(dropdown.getSelected());
}, lv.EVENT_VALUE_CHANGED, null);
```

The current binding provides methods/properties such as options, selected item, direction, symbol, list, text, and open state, including `setOptions`, `setSelected`, `setDir`, `getSelected`, `getSelectedStr`, `getOptionCount`, `close`, and `isOpen`. The dropdown list is still part of the LVGL object tree, and its handle becomes invalid when the parent object is destroyed.
