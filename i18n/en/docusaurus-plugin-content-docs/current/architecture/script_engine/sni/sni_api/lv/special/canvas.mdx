# Canvas

`lv.canvas` is a canvas widget that inherits from `lv.obj`. The current binding provides `setBuffer`, `setDrawBuf`, `setPx`, `setPalette`, `getDrawBuf`, `getPx`, `copyBuf`, `fillBg`, `initBuffer`, and `freeBuffer`, as well as the `buf` and `drawBuf` properties.

```js
const canvas = new lv.canvas(eos.view.active());
canvas.setSize(100, 100);
canvas.initBuffer(100, 100, lv.COLOR_FORMAT_RGB565);
canvas.setPx(10, 10, lv.color.hex(0xffffff));
```

It is not an HTML canvas with an independent JavaScript 2D context; the old examples such as `getContext`, `beginPath`, and `fillRect` do not apply to the current API. The buffer is managed by the caller according to the interface contract, and the related handles cannot continue to be used after being released or deleted.
