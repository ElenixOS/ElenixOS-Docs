# Object

`lv.obj` is the base class for most script controls. It requires a parent object:

```js
const obj = new lv.obj(eos.view.active());
obj.setSize(100, 100);
obj.align(lv.ALIGN_CENTER, 0, 0);
obj.addFlag(lv.OBJ_FLAG_CLICKABLE);
```

The common interface covers position and size (`setPos`, `setSize`, `setX`, `setY`), layout (`align`, `alignTo`, flex/grid), parent-child relationships, flags, styles, events, and deletion. Deleting an object tree may cascade-delete child objects, so after deleting a parent object all child handles must be considered invalid.

Events are registered via `addEventCb(callback, code, userData)`, can be canceled with `removeEventCb` or `removeEventCbWithUserData`, or sent with `sendEvent`. Callbacks execute synchronously in the LVGL context; blocking will delay other work in that context, and handles to deleted objects are already invalid.
