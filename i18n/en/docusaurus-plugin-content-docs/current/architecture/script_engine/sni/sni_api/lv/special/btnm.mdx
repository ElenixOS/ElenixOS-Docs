# Button Matrix

```js
const btnm = new lv.buttonmatrix(eos.view.active());
btnm.setMap(["一", "二", "三", ""]);
btnm.addEventCb(() => {
    eos.console.log(btnm.getSelectedButton());
}, lv.EVENT_VALUE_CHANGED, null);
```

Button Matrix inherits from `lv.obj`. The current binding provides interfaces for the button map, button control properties, selected button, layout, and selection state; the specific map format follows LVGL button matrix rules. It does not have an independent system event bus; interactions are handled through object event callbacks.
