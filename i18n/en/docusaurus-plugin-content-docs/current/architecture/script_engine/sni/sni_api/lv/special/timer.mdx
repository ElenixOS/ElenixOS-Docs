# Timer

`lv.timer` is a script-manageable LVGL timer. It does not require a parent object:

```js
const timer = new lv.timer();
timer.setCb(() => {
    eos.console.log("tick");
});
timer.setPeriod(1000);
timer.setRepeatCount(5);
timer.ready();
```

Current methods include `setCb`, `setPeriod`, `setRepeatCount`, `pause`, `resume`, `reset`, `ready`, `getPaused`, `setAutoDelete`, and `delete`. `setAutoDelete` controls automatic deletion after the timer completes; the current API does not have the older `setPriority`, `setAutoReset`, `start`, `stop`, or `isRunning` methods from the documentation.

Timer callbacks execute in the LVGL main loop. When the application is suspended, Recent Apps pauses and resumes it according to the system timer policy; after the application is fully stopped or the timer is deleted, the callback will not continue to execute.
