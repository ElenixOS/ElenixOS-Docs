# CardPager

CardPager manages a set of pages that can be swiped horizontally or vertically, and provides a page indicator. Pages are created by the component and belong to the CardPager.

```c
eos_card_pager_t *cp = eos_card_pager_create(parent, EOS_CARD_PAGER_DIR_HOR);
lv_obj_t *page = eos_card_pager_create_page(cp);
lv_label_create(page);

eos_card_pager_set_loop(cp, true);
eos_card_pager_move_page(cp, 0);
eos_card_pager_set_page_changed_cb(cp, on_page_changed, user_data);
```

`EOS_CARD_PAGER_DIR_VER` and `EOS_CARD_PAGER_DIR_HOR` represent vertical and horizontal sliding, respectively. Page indices start from 0; pages can be managed via `eos_card_pager_get_page`, `eos_card_pager_get_indicator`, `eos_card_pager_remove_page`, and `eos_card_pager_move_node`.

When loop is enabled, continuing to swipe from the first or last page returns to the other end; when loop is disabled, it stops at the boundary. The page change callback receives the CardPager, the current page index, and the user data registered at the time. Deleting the CardPager's parent object also deletes its pages, and page pointers become invalid as the object tree is destroyed.
