# Swipe Panel

Swipe Panel is an edge-sliding panel based on Slide Widget, supporting four directions: up, down, left, and right. After creation, the panel can be shown, hidden, and moved by gestures or API.

```c
eos_swipe_panel_t *sp = eos_swipe_panel_create(parent);
eos_swipe_panel_set_dir(sp, EOS_SWIPE_DIR_DOWN);
eos_swipe_panel_show(sp);
eos_swipe_panel_pull_back(sp);
eos_swipe_panel_hide_handle_bar(sp);
eos_swipe_panel_delete(sp);
```

The direction constants are `EOS_SWIPE_DIR_UP`, `EOS_SWIPE_DIR_DOWN`, `EOS_SWIPE_DIR_LEFT`, and `EOS_SWIPE_DIR_RIGHT`. `eos_swipe_panel_move(sp, target, anim)` uses absolute coordinates on the display axis; when `anim` is true, animation is performed.

The component contains the panel object, gesture area, and handle bar. The default gesture area is 50 pixels, and the default animation is chosen internally by the component; callers should not rely on the internal object layout. To listen for sliding state, use the public callback registration interface of its internal Slide Widget.
