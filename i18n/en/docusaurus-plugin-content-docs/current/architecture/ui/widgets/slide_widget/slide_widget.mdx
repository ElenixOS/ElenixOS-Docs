# Slide Widget

Slide Widget is a horizontal or vertical slide controller. It makes a target object follow a touch object and, on release, automatically opens or returns to the base position based on a threshold.

## Creation and Control

```c
eos_slide_widget_t *sw = eos_slide_widget_create(
    parent, target_obj, EOS_SLIDE_DIR_HOR, 100, EOS_THRESHOLD_50);

eos_slide_widget_move(sw, 0, 100, 200);
eos_slide_widget_set_bidirectional(sw, true);
eos_slide_widget_reverse(sw);
eos_slide_widget_delete(sw);
```

If a touch object already exists, use `eos_slide_widget_create_with_touch`. `target` is the target coordinate of the target object on the selected axis; thresholds use the 0–255 scale from `EOS_THRESHOLD_0` to `EOS_THRESHOLD_100`, and `EOS_THRESHOLD_INFINITE` disables threshold triggering.

Slide Widget continuously manages the coordinate range of the target object; calling `lv_obj_center` on that object overrides the coordinates maintained by the component.

## States and Callbacks

States include `IDLE`, `DRAGGING`, `THRESHOLD`, `REVERTING`, `ANIMATING`, and `OPEN`. You can read the state, displacement, current position, base/target positions, direction, and touch/target objects.

Callbacks are bound through the registration functions provided by the component, not through the event bus:

```c
eos_slide_widget_add_event_cb_reached_threshold(sw, cb, user_data);
eos_slide_widget_add_event_cb_reverted(sw, cb, user_data);
eos_slide_widget_add_event_cb_moving(sw, cb, user_data);
eos_slide_widget_add_event_cb_done(sw, cb, user_data);
eos_slide_widget_add_event_cb_opened(sw, cb, user_data);
eos_slide_widget_add_event_cb_closed(sw, cb, user_data);
```

Callbacks receive an LVGL event object, and the touch object is the event target. Event types are initialized by the system before the component is created; event IDs are runtime values and do not constitute fixed global constants.
