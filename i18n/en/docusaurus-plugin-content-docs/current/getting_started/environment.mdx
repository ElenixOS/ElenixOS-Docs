# Simulator Environment Setup

This page only lists the host dependencies for ElenixOS-Simulator; it is not a general toolchain checklist for board-level firmware. Platform / Board projects each require their respective SDK, cross-compiler, and flashing tools. For target selection, see [Board-Level Firmware Build Path](./build).

## Required Tools

The Native Simulator's CMake configuration requires CMake 3.10 or higher, a C compiler supporting C99, a C++ compiler supporting C++17, and the SDL2 development library. The build scripts also require Python 3; `kconfiglib` is used for `menuconfig` and generating Kconfig configurations, and the build can fall back to the default configuration if it is not installed.

The WASM Simulator additionally requires the Emscripten SDK and should be configured with `emcmake` after activating the Emscripten environment. FreeRTOS is already provided with the simulator repository and does not need to be downloaded separately.

The project does not declare fixed minimum CPU, memory, or OpenGL specifications in CMake; actual compilation and runtime capability depends on the host, compiler, and SDL2 environment. The Native configuration adds `-march=native` for the compiler, so the compiler needs to support this option.

## Installation Examples

### macOS

```bash
brew install cmake sdl2 python
```

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install build-essential cmake libsdl2-dev python3 python3-pip
```

On Windows, you can use an MSYS2/MinGW environment that the project can recognize SDL2 in; the documentation does not treat any particular Windows toolchain as a runtime requirement. The key is that CMake, the corresponding compiler, and the SDL2 development files are in searchable paths.

## Verification

```bash
cmake --version
python3 --version
```

If `Could NOT find SDL2` appears during Native configuration, please install the SDL2 development package. When using Kconfig, you can install:

```bash
python3 -m pip install kconfiglib
```

## Get Code

```bash
git clone --recursive https://github.com/ElenixOS/ElenixOS-Simulator.git
cd ElenixOS-Simulator
```

After a non-recursive clone, you can fetch the submodules:

```bash
git submodule update --init --recursive
```

After completing environment setup, follow [Simulator Build and Run](../simulator/build) to choose Native or WASM. This page does not cover firmware building, flashing, or on-device verification for any Board.
