# ElenixOS Introduction

ElenixOS is an open-source operating system designed for smartwatches and other resource-constrained wearable devices.It organizes UI, application logic, and system services on a unified scripting runtime, allowing watch faces, system apps, and third-party apps to run in a more consistent manner while retaining efficient access to underlying hardware.

## Core Features

### Script-Driven Application Model

ElenixOS watch faces and applications are uniformly driven by the scripting engine.Scripts are responsible for describing the UI and business logic, while the underlying native code handles scheduling, rendering, and resource management.This layered approach makes applications easier to iterate and easier to migrate across different hardware platforms.

### LVGL + JerryScript Runtime

The graphics layer is based on LVGL, and script execution is powered by JerryScript.The former handles UI rendering and interaction, while the latter executes JavaScript logic on resource-constrained devices.Combined, ElenixOS provides a relatively consistent UI experience and scriptable extension capabilities on wearable devices.

### Layered Architecture

The project splits system capabilities into an application layer, a kernel layer, a portable interface layer, and a hardware layer.The benefit is that upper-layer applications can reliably depend on a unified API, while the underlying implementation can be replaced for different chips, sensors, and peripherals.

### Developer-Facing Toolchain

In addition to the runtime itself, ElenixOS provides development tools such as application packaging and binding layer generation, helping you combine scripts, resources, and native interfaces into deployable application packages.

### Rich Core Modules

ElenixOS provides a series of core modules, including:

* **Application Management**: Supports installation, uninstallation, management, and running of applications.
* **System Services**: Provides system-level services such as battery management and sensor management.
* **UI Components**: Provides a rich set of user interface components based on LVGL.
* **File System**: Supports operations on files and directories.
* **Scripting Engine**: Provides a JavaScript execution environment based on JerryScript.
