## Project Introduction

ElenixOS is an open-source operating system designed for smartwatches and other resource-constrained wearable devices. It organizes UI, application logic, and system services on top of a unified scripting runtime, allowing watch faces, system applications, and third-party apps to run in a more consistent manner while retaining efficient access to underlying hardware.

## Code Block Test

### C Language Code```c
#include "elenix_os.h"

static void app_main(void) {
    // 初始化显示驱动
    display_init();
    // 创建主界面
    lv_obj_t *screen = lv_obj_create(NULL);
    lv_scr_load(screen);
}
```### JavaScript Code```javascript
// 在 ElenixOS 中注册一个表盘应用
const watchface = ElenixOS.registerApp({
  name: '我的表盘',
  type: 'watchface',
  render() {
    // 绘制表盘界面
    ui.drawBackground();
    ui.drawTime();
  },
});
```### Shell Commands```bash
# 克隆 ElenixOS 仓库
git clone https://github.com/ElenixOS/ElenixOS.git
cd ElenixOS
# 初始化子模块
git submodule update --init --recursive
```## Inline Code and Formatting

Use`lv_obj_create(NULL)`to create a new LVGL object. The system achieves efficient communication between **JavaScript** and the *C layer* through`SNI`(Script Native Interface).

The configuration item`LV_USE_ASSERT_MEM_INTEGRITY`should be set to`1`during debugging, but must be set to`0`during performance testing.

## Mixed Content

> The architecture design of ElenixOS follows the principle of "minimal kernel, maximum flexibility." The system core is only responsible for resource management and process scheduling, and all upper-layer functionality is extended through the script engine.
