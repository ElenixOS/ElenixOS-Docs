# Introduction to ElenixOS

ElenixOS is an open-source embedded operating system for smartwatches and other resource-constrained wearable devices. The system Core provides the application model, runtime, Framework, system services, and device abstraction; Platform / BSP projects connect the Core to specific SoCs, Boards, displays, input, storage, and other peripherals.

ElenixOS-Simulator and ElenixOS-Toolkit are auxiliary development tools in the ecosystem: the Simulator helps rapidly iterate on UI, Application / Watch Face, and some platform-independent logic; the Toolkit initializes application projects and builds and analyzes EPKG installation packages. The Simulator's desktop runtime behavior does not represent the drivers and hardware capabilities of a specific Board.

The PSoC Edge E84 port is still in development and has not yet reached a stable port. Developers can also create their own Platform / BSP projects and port to their own SoC or Board.

## System Model

- **Application / Package:** Script applications and watch faces are delivered as EPKG installation packages, and after installation are managed by the Framework under a stable identity.
- **Program / Runtime:** SPM manages script Programs, Realms, and runtime resources; JavaScript enters the Native system through interfaces exposed by SNI.
- **Activity / View:** The Activity Controller manages page relationships and lifecycle; an Activity holds its own LVGL View. Pages and script Programs are two related but independent lifecycles.
- **Framework / Service:** The Framework provides application-facing models, and Services manage system-shared capabilities, state, and policies; Storage, Sensor, Audio, and the like are specific system services.
- **Device / Platform:** The Core defines device and platform contracts; Board / BSP integration implements these boundaries and connects to the target hardware.

For detailed relationships, see [System Architecture](./architecture/arch). The system entry page does not presume the reader's development role, nor does it require everyone to first create an Application project.
