# WASM Simulator Runtime Boundaries

The WASM simulator compiles the same ElenixOS simulator into a browser page via Emscripten. The online version is available at [Online Simulator](https://simulator.elenixos.com/wasm/latest/main.html).

WASM is an auxiliary runtime environment in the browser, not a target for ElenixOS device firmware; its browser file system, input controls, and available device capabilities are limited by the page runtime environment. For board-level build targets, see [Board-Level Firmware Build Path](../getting_started/build).

For WASM configuration, build, and local startup commands, see [Simulator Build and Run](./build). This target requires the Emscripten SDK to be installed and activated.

The build artifacts are located in `build-wasm/bin/` and mainly include:

- `main.html`: Page entry point
- `main.js` and `main.wasm`: Emscripten runtime code
- `main.data`: Preloaded data file (the filename may vary with build configuration)

The WASM build preloads the system file directory into the page's virtual file system; it does not access arbitrary local paths on the host machine.

The simulated display in the browser is 390×450 pixels, and the page shell provides crown and side button controls. The WASM version does not have the Native SDL window or FreeRTOS runtime mode.

## Release Path

The repository's WASM workflow deploys the build results to a path similar to the following:

```text
wasm/latest/main.html
wasm/latest/main.js
wasm/latest/main.wasm
wasm/latest/main.data
```

The specific site URL depends on the deployment repository and branch; when embedding in other pages, use the absolute or relative URL of the deployed `main.html`, and ensure that the JS, WASM, and data files in the same directory are accessible.
