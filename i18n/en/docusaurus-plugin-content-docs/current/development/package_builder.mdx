# Legacy Script Packaging Notes

This page retains the legacy documentation path for existing links to reference the migration direction. `eos_pkg_builder.py` is a legacy standalone packaging tool, currently marked as deprecated / legacy, and is no longer the recommended build method for new application or watch face projects.

For the region semantics and system interpretation rules of the current EPKG v1 package, see [EPKG v1 Installation Package Format](../architecture/package_format); for project initialization, building, analysis, and other development workflows, see [ElenixOS-Toolkit](./toolkit).
