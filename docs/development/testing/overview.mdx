# 测试体系概述

当前测试应用建立在 LVGL 运行时之上，提供交互式测试页面和同步测试框架。它不是独立的 headless 命令行测试程序。

## 测试框架

测试以名称和函数注册到固定容量的测试表中。执行器可以按选择执行全部或部分测试，并在 GUI 页面和日志中显示结果。重复名称不会创建第二个测试；超过编译期容量的测试不会被加入。

测试函数在当前调用中同步执行，使用框架提供的记录/断言接口写入结果。测试返回后，执行器继续处理下一个选中的测试；当前实现没有把一个测试挂起到多个 LVGL tick 后再结算的通用异步协议。

## GUI 页面

测试应用提供测试列表、分组选择、运行进度和结果显示。需要持续观察或人工操作的功能（例如 UI、传感器和音频）应使用独立的交互式页面；这种页面的结果不会自动计入同步测试框架的统计。

## 编译期开关

测试应用由 `EOS_ENABLE_TEST_APP` 控制。关闭该配置后，测试应用相关代码不参与构建。启用后，测试仍需要完整的 LVGL/系统运行时初始化。

## 当前限制

- 没有独立 headless runner，不能仅通过测试框架 API 在纯控制台环境运行一套测试。
- 测试函数必须在返回前完成验证；不能依赖异步回调改变已经记录的结果。
- 测试和分组使用固定容量，具体上限由当前测试框架的编译配置决定。
- 测试注册应在测试页面创建前完成，否则新条目不会出现在已经构建的列表中。
