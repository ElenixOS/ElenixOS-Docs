# 开发工具

当前模拟器仓库中与日常开发直接相关的工具主要是 CMake/Makefile、Kconfig 配置工具和脚本包构建器。

## 构建与配置

```bash
cmake -S . -B build
cmake --build build --parallel
cmake --build build --target menuconfig
```

`menuconfig` 使用 `kconfiglib` 生成构建目录中的 `.config` 和生成配置头文件。配置的覆盖顺序和可用选项见[内核配置系统](./kconfig)。

## 脚本包构建器

`ElenixOS/scripts/eos_pkg_builder.py` 接受输入目录、输出文件两个位置参数，`--type` 可选：

```bash
python3 ElenixOS/scripts/eos_pkg_builder.py app/ app.epk
python3 ElenixOS/scripts/eos_pkg_builder.py watchface/ watchface.epk --type watchface
```

它读取输入目录的 `manifest.json`，收集目录中的文件并生成 `.epk` 二进制包；`--type` 决定包头中的 Application/Watch Face 类型。当前不压缩资源，也没有 `--input`、`--output`、`--compress` 或 `--verbose` 参数。详见[构建脚本包](./package_builder)。

## 运行与日志

Native 构建产物为仓库根目录 `bin/main`，运行时日志写入 `tmp/latest.log` 并按时间归档。WASM 构建产物在构建目录的 `bin/`，需要 HTTP 服务器提供给浏览器。

仓库没有文档中旧版所称的通用 `build.sh`、`clean.sh`、`eos_log_i` 等工具接口；日志请使用 `EOS_LOG_D/I/W/E` 或脚本侧的 `eos.console.*`。
