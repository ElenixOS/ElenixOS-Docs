# Simulator 构建工具与日志

本页介绍 ElenixOS-Simulator 仓库中的 CMake / Makefile、Kconfig 和 Native 日志入口。它们是桌面 Simulator 的主机侧工具，不是各 Board 固件的统一构建接口。Application / Watch Face 项目、EPKG 构建和分析由 [ElenixOS-Toolkit](./toolkit)负责；板级固件按[Platform 与 Board 集成](../integration/overview)和对应工程的说明构建。

## 构建与配置

```bash
cmake -S . -B build
cmake --build build --parallel
cmake --build build --target menuconfig
```

`menuconfig` 使用 `kconfiglib` 生成构建目录中的 `.config` 和生成配置头文件。配置的覆盖顺序和可用选项见[内核配置系统](./kconfig)。

## Application / Watchface 开发

项目初始化、EPKG 安装包构建和现有包分析由官方 VS Code 插件 [ElenixOS-Toolkit](./toolkit) 提供。安装包格式本身由[EPKG v1 安装包格式](../architecture/package_format)定义。

模拟器仓库中的 `ElenixOS/scripts/eos_pkg_builder.py` 是旧版独立打包工具，当前已处于 deprecated / legacy 状态，不再作为新 Application 或 Watchface 项目的推荐构建入口。

## 运行与日志

Native 构建产物为仓库根目录 `bin/main`，运行时日志写入 `tmp/latest.log` 并按时间归档。WASM 构建产物在构建目录的 `bin/`，需要 HTTP 服务器提供给浏览器。

仓库没有文档中旧版所称的通用 `build.sh`、`clean.sh`、`eos_log_i` 等工具接口；日志请使用 `EOS_LOG_D/I/W/E` 或脚本侧的 `eos.console.*`。
