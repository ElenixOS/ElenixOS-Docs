# ElenixOS 介绍

ElenixOS 是面向智能手表和其他资源受限可穿戴设备的开源嵌入式操作系统。系统 Core 提供应用模型、运行时、Framework、系统服务和设备抽象；Platform / BSP 工程把 Core 接到具体 SoC、Board、显示、输入、存储和其他外设。

ElenixOS-Simulator 和 ElenixOS-Toolkit 是生态中的辅助开发工具：Simulator 帮助快速迭代 UI、Application / Watch Face 及部分平台无关逻辑；Toolkit 初始化应用项目并构建、分析 EPKG 安装包。Simulator 的桌面运行行为不代表具体 Board 的驱动与硬件能力。

PSoC Edge E84 移植仍处于开发阶段，尚未形成稳定移植。开发者也可以自行创建 Platform / BSP 工程并移植到自有 SoC 或 Board。

## 系统模型

- **Application / Package：** 脚本应用和表盘以 EPKG 安装包交付，安装后由 Framework 按稳定身份管理。
- **Program / Runtime：** SPM 管理脚本 Program、Realm 和运行时资源；JavaScript 通过 SNI 暴露的接口进入 Native 系统。
- **Activity / View：** Activity Controller 管页面关系和生命周期；Activity 持有自己的 LVGL View。页面和脚本 Program 是两个相关但独立的生命周期。
- **Framework / Service：** Framework 提供面向应用的模型，Service 管系统共享能力、状态和策略；Storage、Sensor、Audio 等属于具体系统服务。
- **Device / Platform：** Core 定义设备与平台契约；Board / BSP 集成实现这些边界，并接入目标硬件。

详细关系见[系统架构](./architecture/arch)。系统入口页不预设读者的开发角色，也不要求所有人先建立 Application 项目。
