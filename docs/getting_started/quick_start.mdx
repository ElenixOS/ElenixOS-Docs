# 快速开始

ElenixOS 是面向智能手表和资源受限可穿戴设备的开源嵌入式操作系统。ElenixOS Core 提供 Framework、脚本运行时、系统服务和设备抽象；Platform / BSP 工程把这些系统能力接到具体 SoC、Board 和外设。应用包、板级固件与 Simulator 桌面程序是不同的交付物。

```mermaid
flowchart LR
    App["Application / Watch Face"] -->|公开系统接口| Core["ElenixOS Core"]
    Core -->|定义 Device / port 契约| Platform["Platform / BSP"]
    Platform -.->|实现并注册设备| Core
    Platform -->|集成| Board["SoC / Board"]
    Board -->|设备数据与状态| Platform
```

开发工具和 Simulator 是按任务选择的辅助环境，不是系统运行时的一部分。

当前公开的 PSoC Edge E84 集成仍处于开发阶段，尚未形成稳定移植。Simulator 适合桌面 UI 与部分平台无关逻辑迭代，不代替板级驱动、功耗、时序和烧录验证。

## 三种不同的构建产物

- **板级固件**由 Platform / BSP 工程针对 SoC 和 Board 构建并烧录。项目、工具链、配置和下载方式由具体平台工程定义；从[板级固件构建路径](./build)选择目标。
- **Application / Watch Face 安装包**由开发工作流生成 `.epk`，之后安装到已经运行 ElenixOS 的系统；它不是固件镜像。
- **Simulator**由主机工具链构建为桌面程序或 WASM 页面，用于辅助开发；它不生成 Board 固件。

公共入口到此为止。各角色的完整命令、代码、配置、部署和预期结果位于对应的任务教程；接口查询见 [JavaScript API 参考](../architecture/script_engine/elenix_os)。
