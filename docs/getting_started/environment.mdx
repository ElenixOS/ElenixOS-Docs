# Simulator 环境准备

本页只列出 ElenixOS-Simulator 的主机依赖，不是板级固件的通用工具链清单。Platform / Board 工程各自需要相应 SDK、交叉编译器和下载工具，目标选择见[板级固件构建路径](./build)。

## 必需工具

Native Simulator 的 CMake 配置要求 CMake 3.10 或更高版本、支持 C99 的 C 编译器、支持 C++17 的 C++ 编译器和 SDL2 开发库。构建脚本还需要 Python 3；`kconfiglib` 用于使用 `menuconfig` 和生成 Kconfig 配置，未安装时构建可回退到默认配置。

WASM Simulator 另外需要 Emscripten SDK，并且应在激活 Emscripten 环境后使用 `emcmake` 配置。FreeRTOS 已随模拟器仓库提供，不需要另行下载。

项目没有在 CMake 中声明固定的 CPU、内存或 OpenGL 最低规格；实际编译和运行能力取决于主机、编译器与 SDL2 环境。Native 配置会为编译器加入 `-march=native`，因此编译器需要支持该选项。

## 安装示例

### macOS

```bash
brew install cmake sdl2 python
```

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install build-essential cmake libsdl2-dev python3 python3-pip
```

Windows 可使用项目能够识别 SDL2 的 MSYS2/MinGW 环境；文档不把某个 Windows 工具链作为运行时要求，关键是 CMake、对应编译器和 SDL2 开发文件位于可搜索路径中。

## 验证

```bash
cmake --version
python3 --version
```

Native 配置时若出现 `Could NOT find SDL2`，请安装 SDL2 开发包。使用 Kconfig 时可安装：

```bash
python3 -m pip install kconfiglib
```

## 获取代码

```bash
git clone --recursive https://github.com/ElenixOS/ElenixOS-Simulator.git
cd ElenixOS-Simulator
```

非递归克隆后可补齐子模块：

```bash
git submodule update --init --recursive
```

完成环境准备后，按[Simulator 构建与运行](../simulator/build)选择 Native 或 WASM。此页不覆盖任何 Board 的固件构建、烧录或设备端验证。
