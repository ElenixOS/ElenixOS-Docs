# 构建与使用

ElenixOS-Simulator 使用 CMake 构建，默认目标是 Native，也可以使用 Emscripten 构建 WASM。首次获取代码时需要初始化子模块。

```bash
git clone --recursive https://github.com/ElenixOS/ElenixOS-Simulator.git
cd ElenixOS-Simulator
```

如果已经克隆了仓库：

```bash
git submodule update --init --recursive
```

## Native

Native 构建需要 SDL2 开发库。使用 Debug 构建并运行：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
./bin/main
```

也可以在已经存在 `build/` 配置目录时使用根目录 Makefile 的快捷目标：

```bash
make              # 构建已经配置好的 build/
make run          # 构建后运行 Native 模拟器
```

Native 模拟器的模拟屏幕为 390×450 像素；窗口还包含用于模拟表冠和侧边按钮的控件。窗口缩放不会改变系统报告的显示分辨率。

## WASM

WASM 构建需要已激活的 Emscripten 工具链：

```bash
emcmake cmake -S . -B build-wasm -DEOS_PLATFORM=WASM -DCMAKE_BUILD_TYPE=Release
cmake --build build-wasm --parallel
```

产物位于 `build-wasm/bin/`，包括 `main.html`、`main.js`、`main.wasm` 和预加载数据文件。浏览器需要通过 HTTP 服务器访问：

```bash
cd build-wasm/bin
python3 -m http.server 8000
```

然后打开 [http://localhost:8000/main.html](http://localhost:8000/main.html)。不能直接用 `file://` 打开页面。

## CMake 选项

| 选项 | 默认值 | 作用 |
|---|---:|---|
| `EOS_PLATFORM` | `Native` | 选择 `Native` 或 `WASM` |
| `USE_FREERTOS` | `OFF` | Native 下启用 FreeRTOS；WASM 下会被禁用 |
| `LV_USE_DRAW_SDL` | `OFF` | 启用 SDL 绘制后端，并需要对应 SDL2_image 依赖 |
| `LV_USE_LIBPNG` | `OFF` | 启用 PNG 支持 |
| `LV_USE_LIBJPEG_TURBO` | `OFF` | 启用 JPEG 支持 |
| `LV_USE_FFMPEG` | `OFF` | 启用 FFmpeg 支持 |
| `LV_USE_FREETYPE` | `OFF` | 启用 FreeType 支持 |
| `ASAN` | `OFF` | Debug 构建时启用 Address/Leak/Undefined sanitizer |

上述可选后端只有在依赖库可被 CMake 找到时才能启用。

## Kconfig

内存策略、字体、显示参数、日志和 Recent Apps 等配置通过 Kconfig 管理：

```bash
cmake -B build
cmake --build build --target menuconfig
```

配置保存在对应构建目录的 `.config` 中，生成头文件位于 `build/generated/`。详见[内核配置系统](../development/kconfig)。

## 日志与故障排查

Native 运行时会把当前日志写入模拟器仓库的 `tmp/latest.log`，旧日志按时间归档。遇到 SDL2 找不到、子模块缺失或链接错误时，先确认依赖和 `git submodule update --init --recursive`，再使用一个新的构建目录重新配置。
