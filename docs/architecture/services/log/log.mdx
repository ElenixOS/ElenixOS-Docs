# 日志服务

日志服务提供四个级别：`DEBUG`、`INFO`、`WARN` 和 `ERROR`。宏 `EOS_LOG_D`、`EOS_LOG_I`、`EOS_LOG_W`、`EOS_LOG_E` 会格式化消息并交给日志服务；定义 `EOS_LOG_DISABLE` 时，这些宏不产生输出。

## 级别过滤

```c
eos_log_level_t eos_log_get_level(void);
eos_result_t eos_log_set_level(eos_log_level_t level);
```

这是日志服务的全局最低派发级别。低于该级别的消息不会派发给监听器。

## 监听器

日志监听器收到级别、消息缓冲区、消息长度和注册时的用户数据：

```c
typedef void (*eos_log_listener_cb_t)(eos_log_level_t level,
                                      const char *buf,
                                      size_t len,
                                      void *user);

eos_log_listener_id_t eos_log_register_listener(const char *name,
                                                eos_log_listener_cb_t cb,
                                                void *user_data,
                                                uint8_t flags);
eos_result_t eos_log_unregister_listener(eos_log_listener_id_t id);
eos_result_t eos_log_set_listener_enabled(eos_log_listener_id_t id,
                                          bool enabled);
eos_log_listener_id_t eos_log_find_listener(const char *name);
eos_result_t eos_log_get_listener(eos_log_listener_id_t id,
                                  eos_log_listener_t *listener);
```

注册成功返回非负 ID，失败返回 `-1`。监听器名称必须在其生命周期内保持有效，通常应使用静态字符串。`EOS_LOG_FLAG_SYSTEM` 用于系统监听器；带该标志的监听器不能被注销。禁用监听器不会删除它，之后可重新启用。

系统启动时调用 `eos_service_log_init()`；标准输出监听器可通过 `eos_service_log_std_register()` 注册。日志宏中的 `EOS_LOG_TAG` 会作为消息前缀使用，彩色输出是否启用由 `EOS_LOG_USE_COLOR` 决定。

日志监听器回调应尽快返回，也不应假定消息缓冲区在回调返回后仍然有效。
