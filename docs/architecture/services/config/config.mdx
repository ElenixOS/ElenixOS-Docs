# 配置服务

配置服务管理系统级设置并将其保存为 JSON。配置项覆盖设备与语言、显示和电源、音频与触觉、表盘和应用排序，以及安全选项。系统模块通过类型化配置访问，不应自行解析或改写系统配置文件。

读取缺失值或类型不匹配的配置项时使用调用方提供的默认值。动态字符串和 JSON 树由调用方按各自的资源规则释放。开发调试选项也可能作为普通配置数据保存，并不因此成为编译期配置。

脚本配置与系统配置相互隔离，并按应用或表盘的数据目录保存；系统级配置不属于脚本配置边界。

配置服务是同步的 Core-owned 设置快照，缺键时由读取方提供默认语义；它不是实时设备数据订阅。JS `eos.config` 根据当前脚本身份写到对应应用/表盘配置位置，而通用 Storage API 不会自动施加此身份隔离。调用层见[Application 契约](../../application_contract)。
