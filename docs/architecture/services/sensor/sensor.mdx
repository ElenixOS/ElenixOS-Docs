# 传感器服务

传感器服务统一提供传感器数据读取、订阅和采样周期管理。当前实现同时支持 Pull 和 Push 两种方式；两者都由服务维护的数据缓存提供数据。

## 读取数据

```c
eos_result_t eos_sensor_read(eos_sensor_type_t type,
                             eos_sensor_raw_data_t *data);
eos_result_t eos_sensor_read_latest(eos_sensor_type_t type,
                                    eos_sensor_raw_data_t *data);
```

`eos_sensor_read` 从该类型的 FIFO 读取一条数据；FIFO 容量为 `EOS_SENSOR_FIFO_CAPACITY`，当前值为 64；FIFO 为空时返回未找到错误。`eos_sensor_read_latest` 复制当前缓存的最新数据，对于已初始化且有效的类型当前会返回成功；在驱动尚未上报数据前，缓存仍是零初始化值，调用方不能仅靠返回码判断是否已有真实样本。类型不存在或参数无效时，接口通过 `eos_result_t` 报告失败。

## 订阅数据

```c
typedef void (*eos_sensor_data_cb_t)(eos_sensor_type_t type,
                                     const eos_sensor_raw_data_t *data,
                                     void *user_data);

eos_result_t eos_sensor_subscribe(eos_sensor_type_t type,
                                  eos_sensor_data_cb_t cb,
                                  void *user_data,
                                  uint32_t min_interval_ms);
eos_result_t eos_sensor_unsubscribe(eos_sensor_type_t type,
                                    eos_sensor_data_cb_t cb,
                                    void *user_data);
```

回调收到传感器类型、带时间戳的数据指针和订阅时传入的 `user_data`。数据指针由服务拥有，回调若需在返回后使用必须自行复制。`min_interval_ms` 是该订阅者要求的最小通知间隔，实际采样还会受到当前传感器模式策略限制。

## 采样与模式策略

```c
eos_result_t eos_sensor_set_sample_period(eos_sensor_type_t type,
                                           uint32_t period_ms);
uint32_t eos_sensor_get_sample_period(eos_sensor_type_t type);

eos_result_t eos_sensor_set_mode_policy(eos_sensor_mode_t mode,
                                        const eos_sensor_policy_t *policy);
eos_result_t eos_sensor_get_mode_policy(eos_sensor_mode_t mode,
                                        eos_sensor_policy_t *policy);
eos_sensor_mode_t eos_sensor_get_current_mode(void);
```

每个模式策略包含最小采样间隔和是否允许启用传感器两个条件。将 `policy` 传为 `NULL` 会恢复指定模式的默认策略。服务当前定义 `NORMAL`、`LOW_POWER`、`ACTIVE` 和 `SLEEP` 四种模式。

`eos_sensor_notify` 是驱动向服务提交数据的接口，不是应用读取数据的接口：

```c
void eos_sensor_notify(eos_sensor_type_t type,
                       const eos_sensor_data_t *data,
                       uint32_t timestamp);
```

传感器服务使用前应先调用 `eos_service_sensor_init()`。传感器的具体可用类型和原始数据字段由设备层的 `eos_sensor_type_t` 与 `eos_sensor_raw_data_t` 定义。
