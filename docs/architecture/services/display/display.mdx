# 显示服务

显示服务协调亮度和屏幕电源状态。平台显示端口执行具体操作，服务管理系统请求及其效果。

亮度取值为 0–100。亮度变化可以立即生效或使用预设过渡时长；临时亮度会保留先前值，供系统恢复。显示电源控制用于唤醒或关闭屏幕，不应由应用绕过电源管理策略直接操作平台端口。

Display Service 同步调用设备亮度操作并维护请求值；设备表的 brightness 操作为必需项，power on/off 是可选项且当前没有物理完成回调。LVGL framebuffer、刷新和输入设备由平台图形 HAL 提供，不属于亮度/电源操作表。应用观察亮度状态不等于设备确认。见[Application 契约](../../application_contract)和[Platform/Vendor 契约](../../platform_contract)。
