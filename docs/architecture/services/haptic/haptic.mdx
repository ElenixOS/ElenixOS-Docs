# 触觉服务

触觉服务把系统反馈请求映射到平台振动设备。设备缺失或操作不受支持时，服务按设备能力和操作结果报告；静默无效果不构成成功确认。

服务提供关闭、普通和增强三档全局强度，以及短促、较强和长时等反馈语义。具体波形与持续时间由平台实现决定；调用方表达反馈意图，不直接控制振动硬件。

Core 按反馈意图同步调用 Vibrator 的 on/off 操作；Vendor 决定实际波形和设备强度。操作没有返回值，当前 Service 不提供逐次振动完成或硬件成功事件，因此应用不能依赖某次请求一定产生可感知振动。平台边界见[Platform/Vendor 契约](../../platform_contract)。
