# 任务调度器

任务调度器把其他线程或中断上下文中的短任务提交到系统主循环，在适合执行界面和系统逻辑的上下文中依次处理。它是跨上下文的延后执行队列，不是通用线程调度器。

## 队列与执行

调度器使用受临界区保护的环形队列保存回调及其用户数据。队列空间不足时会尝试扩容；内存分配失败可能导致新任务丢失。队列中的任务由主循环按提交顺序处理，执行回调期间会释放队列保护，以便其他上下文继续提交工作。

## 使用边界

提交方应保持回调短小，并保证用户数据在任务执行前有效。中断中只收集必要信息并提交后续工作；需要操作 LVGL 的任务必须在 GUI 主循环中执行。队列不提供任务优先级、取消或可靠持久化保证。
