# 事件总线

事件总线按事件标识同步广播系统状态变化。它用于通知应用安装、系统电源与显示状态、脚本生命周期、页面切换和语言变化；它不是异步消息队列，也不替代 Activity 栈或 LVGL 控件事件。

## 发布与订阅

模块可订阅所需事件并在不再需要通知时取消订阅。订阅可关联对象以便管理订阅生命周期，但关联对象不会把全局广播变成定向消息。

事件回调在发布过程同步执行，并继承发布者所在的线程/task/中断上下文；Event Bus 不会自动把它们送到 LVGL 主循环。因此发布方从 ISR 发布时，所有订阅者也可能在 ISR 内执行。需要 GUI/文件/脚本操作时，回调应复制必要数据并交给 Dispatcher 延后处理，或发布方本身先 defer 再发布。

发布者提供的 `param` 和关联对象都是借用资源：回调只可在所有者保证的生命周期内使用；需要跨回调保存时，订阅方必须复制数据或建立明确的所有权关系。电池变化、页面切换等事件传递的是服务/页面状态，而不是状态对象所有权。

回调中可以请求取消订阅；若正在广播，实际节点清理会延迟到安全点。模块应在 owner 销毁时清理关联订阅，避免回调继续访问过期对象。

运行时注册的事件标识只在当前进程实例内有效，不应保存为持久协议编号。

Event Bus 只定义同步广播协议，不提供延后执行、线程安全回调或后台队列语义。跨上下文提交见[任务调度器](../scheduler/dispatcher)。
