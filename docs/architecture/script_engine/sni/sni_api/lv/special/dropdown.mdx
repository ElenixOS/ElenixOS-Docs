---
title: 下拉菜单 (Dropdown)
sidebar_position: 5
---

```js
const dropdown = new lv.dropdown(eos.view.active());
dropdown.setOptions("第一项\n第二项");
dropdown.setSelected(0);
dropdown.addEventCb(() => {
    eos.console.log(dropdown.getSelected());
}, lv.EVENT_VALUE_CHANGED, null);
```

当前绑定提供 options、选中项、方向、符号、列表、文本和打开状态等方法/属性，包括 `setOptions`、`setSelected`、`setDir`、`getSelected`、`getSelectedStr`、`getOptionCount`、`close` 和 `isOpen`。下拉列表仍然是 LVGL 对象树的一部分，父对象销毁时其句柄失效。
