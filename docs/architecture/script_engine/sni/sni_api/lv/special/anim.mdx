# 动画 (Animation)

`lv.anim` 是脚本可配置的 LVGL 动画对象：

```js
const anim = new lv.anim();
anim.init();
anim.setVar(obj);
anim.setValues(0, 100);
anim.setDuration(300);
anim.setCustomExecCb((_anim, value) => obj.setX(value));
anim.setPathCb(anim.pathEaseInOut());
anim.start();
```

构造后必须调用 `init()`，再设置变量和其他参数。当前绑定提供动画初始化、变量、时长/延迟、起止值、自定义执行回调、路径回调、完成/删除回调、播放、重复和 `start` 等方法；路径函数以 `pathLinear`、`pathEaseIn`、`pathEaseOut`、`pathEaseInOut` 等实例方法提供，并返回可传给 `setPathCb` 的内置路径值。自定义执行回调收到 `(anim, value)`，通常通过闭包操作要更新的对象。旧版示例中的全局 `lv.anim_path_ease_in_out` 和 `setExecCb` 不是当前接口名。

动画回调在 LVGL 主循环中执行。Activity/View 或动画所属脚本上下文销毁后，动画句柄失效；应用挂起时由 Recent Apps 按动画恢复策略继续或跳到结束状态。
