# 定时器 (Timer)

`lv.timer` 是脚本可管理的 LVGL 定时器。它不需要父对象：

```js
const timer = new lv.timer();
timer.setCb(() => {
    eos.console.log("tick");
});
timer.setPeriod(1000);
timer.setRepeatCount(5);
timer.ready();
```

当前方法包括 `setCb`、`setPeriod`、`setRepeatCount`、`pause`、`resume`、`reset`、`ready`、`getPaused`、`setAutoDelete` 和 `delete`。`setAutoDelete` 控制定时器完成后的自动删除；当前 API 没有文档中旧版的 `setPriority`、`setAutoReset`、`start`、`stop` 或 `isRunning` 方法。

定时器回调在 LVGL 主循环中执行。应用挂起时，Recent Apps 会按系统 timer 策略暂停和恢复它；应用被完整停止或定时器被删除后，回调不会继续执行。
