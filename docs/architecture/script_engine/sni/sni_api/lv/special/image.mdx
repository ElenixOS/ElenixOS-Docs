---
title: 图片 (Image)
sidebar_position: 6
---

`lv.image` 用于显示图片资源：

```js
const image = new lv.image(eos.view.active());
image.setSrc("/path/to/image.png");
image.setScale(256);
```

当前绑定提供 `setSrc`、偏移、旋转、pivot、缩放、混合模式、抗锯齿和内部对齐等接口，以及对应读取属性。图片源必须是当前端口支持的资源路径或数据；路径访问仍受脚本包/存储边界限制。`setOpacity` 不是当前 `lv.image` 方法，应使用对象样式接口设置透明度。
