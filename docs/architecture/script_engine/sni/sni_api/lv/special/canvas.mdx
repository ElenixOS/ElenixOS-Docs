---
title: 画布 (Canvas)
sidebar_position: 4
---

`lv.canvas` 是继承 `lv.obj` 的画布控件。当前绑定提供 `setBuffer`、`setDrawBuf`、`setPx`、`setPalette`、`getDrawBuf`、`getPx`、`copyBuf`、`fillBg`、`initBuffer` 和 `freeBuffer`，也提供 `buf`、`drawBuf` 属性。

```js
const canvas = new lv.canvas(eos.view.active());
canvas.setSize(100, 100);
canvas.initBuffer(100, 100, lv.COLOR_FORMAT_RGB565);
canvas.setPx(10, 10, lv.color.hex(0xffffff));
```

它不是带有独立 JavaScript 2D context 的 HTML canvas；旧版 `getContext`、`beginPath`、`fillRect` 等示例不适用于当前 API。缓冲区由调用方按接口约定管理，释放或删除后不能继续使用相关句柄。
