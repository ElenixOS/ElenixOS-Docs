# 按钮矩阵 (Button Matrix)

```js
const btnm = new lv.buttonmatrix(eos.view.active());
btnm.setMap(["一", "二", "三", ""]);
btnm.addEventCb(() => {
    eos.console.log(btnm.getSelectedButton());
}, lv.EVENT_VALUE_CHANGED, null);
```

按钮矩阵继承 `lv.obj`。当前绑定提供按钮 map、按钮控制属性、选中按钮、布局和选中状态等接口；具体 map 格式遵循 LVGL 按钮矩阵规则。它没有独立的系统事件总线，交互通过对象事件回调处理。
