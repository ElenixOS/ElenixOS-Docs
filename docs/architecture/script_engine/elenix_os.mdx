# ElenixOS JavaScript API 参考

脚本通过全局对象 `eos` 使用 ElenixOS 提供的系统 API。下面的名称来自当前运行时实际挂载的接口；未列出的 C API 不会因为存在对应的原生函数而自动出现在 JS 中。

## `eos.view`

```js
const view = eos.view.active();
```

`active()` 返回当前活动 View 的句柄。

## `eos.console`

```js
eos.console.log("message");
eos.console.info("info");
eos.console.warn("warning");
eos.console.error("error");
eos.console.debug("debug");
```

每个方法至少需要一个字符串参数，当前实现只处理第一个参数。日志会带上当前脚本 ID。

## `eos.config`

```js
eos.config.setStr("key", "value");
eos.config.setBool("enabled", true);
eos.config.setNumber("count", 3);

const s = eos.config.getStr("key");
const b = eos.config.getBool("enabled");
const n = eos.config.getNumber("count");
```

配置按脚本 ID 隔离：应用和表盘分别写入自己的数据目录中的 `config.json`。写入方法没有有用的返回值；读取时，缺失或类型不匹配的字符串为 `undefined`，布尔值为 `false`，数字为 `0`。配置文件无法加载时会抛出异常。

## `eos.time`

```js
const now = eos.time.getNow();
```

返回对象包含 `year`、`month`、`day`、`hour`、`min`、`sec`、`ms` 和 `day_of_week` 数字字段。字段取值约定与系统 `eos_datetime_t` 一致。

## `eos.appHeader`

```js
eos.appHeader.setTitle(view, "标题");
eos.appHeader.show();
eos.appHeader.hide();
```

`setTitle` 的第一个参数可以是 View 句柄或 `null`，标题必须是字符串；传入 `null`/`undefined` 可清除标题。`show` 和 `hide` 操作当前页面的应用头部。

## `eos.activity`

```js
const activity = eos.activity.create();
eos.activity.setType(activity, eos.ACTIVITY_TYPE_APP);
eos.activity.setTitle(activity, "详情");
eos.activity.enter(activity);

const current = eos.activity.current();
const visible = eos.activity.visible();
const view = eos.activity.getView(current);
const ok = eos.activity.back();
```

当前可用方法：

| 方法 | 行为 |
|---|---|
| `create()` | 创建一个普通 Activity，返回句柄 |
| `destroy(activity)` | 销毁不在栈中且不可见的 Activity |
| `current()` / `visible()` / `bottom()` / `watchface()` | 获取相应 Activity 句柄 |
| `getView(activity)` / `setView(activity, view)` | 读取或设置 View |
| `getTitle(activity)` / `setTitle(activity, title)` | 读取或设置标题 |
| `getType(activity)` / `setType(activity, type)` | 读取或设置类型 |
| `setAppHeaderVisible(activity, visible)` / `isAppHeaderVisible(activity)` | 管理应用头部 |
| `enter(activity)` | 将 Activity 压入并进入页面栈 |
| `back()` | 返回上一页面，返回布尔值表示调用结果 |
| `isTransitionInProgress()` | 查询页面过渡是否进行中 |

`setView` 仅在 Activity 进入流程允许的时机生效，系统管理的 View 由 Activity 生命周期控制。`rootScreen()` 虽出现在 `eos.activity` 名称表中，但在 JS 中调用会抛出“不可用”异常，因此不构成脚本获取根屏幕的 API。

脚本可见的 Activity 类型常量为 `ACTIVITY_TYPE_NULL`、`ACTIVITY_TYPE_APP`、`ACTIVITY_TYPE_APP_LIST`、`ACTIVITY_TYPE_WATCHFACE` 和 `ACTIVITY_TYPE_WATCHFACE_LIST`。`INPUT_PAGE`、`LOCK_SCREEN`、`RECENT_APPS` 等 C 层类型当前未导出为 JS 根常量。

## `eos.permission`

```js
eos.permission.request("sensor", result => {
  // granted_once、granted_foreground、granted_always 或 denied
});

const state = eos.permission.check("sensor");
```

请求必须使用 manifest 中已声明的权限名称。请求是异步的，会在需要时显示授权面板；已经拥有长期或前台授权时也会异步回调。`check` 返回 `once`、`foreground`、`always`、`denied`，未知权限返回 `unknown`。同一权限类别已有请求在处理或排队时，重复请求会被丢弃。

## `eos.sensor`

```js
const data = eos.sensor.readLatest(eos.SENSOR_ACCE);
const changed = eos.sensor.setSamplePeriod(eos.SENSOR_ACCE, 100);
const period = eos.sensor.getSamplePeriod(eos.SENSOR_ACCE);
```

对于已初始化且有效的类型，`readLatest` 返回缓存对象；驱动尚未上报数据时，`timestamp` 和数据字段仍为零，因此返回对象本身不表示已有样本。无效类型或底层调用失败时才返回 `null`。返回对象总有 `timestamp`；加速度、陀螺仪和磁力计使用 `x/y/z`，其他类型使用对应字段：`heart_rate`、`spo2`、`lux`、`temp`、`pressure`、`steps`、`distance_mm`、`ecg` 或 `cap`。JS API 没有原始 Sensor 订阅接口；语义化订阅见下方 `eos.metric`。

## `eos.metric`

```js
const sample = eos.metric.get("battery.percent");
const handle = eos.metric.subscribe("health.heart_rate", sample => {
  // sample contains metric, value, unit, timestamp, valid, stale
});
eos.metric.unsubscribe(handle);
```

Metric 是面向脚本的语义数据接口，不等同于原始传感器 API。读取会返回标准样本；订阅按间隔回调，句柄归属当前脚本上下文，并随退订或上下文清理而失效。样本可能无效或过期，调用方结合 `valid`、`stale` 和 `value` 判断样本状态。

## `eos.clockHand`

```js
const hand = eos.clockHand.create(parent, "hour.png", eos.CLOCK_HAND_HOUR, 0, 0);
eos.clockHand.placePivot(hand, 10, 20);
eos.clockHand.centerStyle(hand, 10, 20);
eos.clockHand.attach(hand, eos.CLOCK_HAND_HOUR);
eos.clockHand.center(hand);
```

`create` 的图片路径相对于当前应用或表盘的 `assets/` 目录，文件必须存在。类型使用 `CLOCK_HAND_HOUR`、`CLOCK_HAND_MINUTE` 或 `CLOCK_HAND_SECOND`。各方法参数不匹配或资源不存在时会抛出异常。

## `eos.ww`

`eos.ww` 提供表盘专用的原生 LVGL 组件工厂。当前暴露的主要组件包括模拟表盘、指南针表盘、径向仪表、Metric 环、趋势图和日历网格；部分组件可绑定 `eos.metric` 的语义名，也可由脚本直接设置值或数据。组件句柄归属于传入的父 View。具体方法与选项以 SNI 当前导出为准；该命名空间不是运行时动态插件注册表。

## 常量

根对象当前导出：

- 字体：`FONT_SIZE_LARGE`、`FONT_SIZE_MEDIUM`、`FONT_SIZE_SMALL`
- 显示：`DISPLAY_WIDTH`、`DISPLAY_HEIGHT`（取决于平台显示配置）
- 表冠指针：`CLOCK_HAND_HOUR`、`CLOCK_HAND_MINUTE`、`CLOCK_HAND_SECOND`
- Activity：上文列出的五个 `ACTIVITY_TYPE_*`
- 传感器：`SENSOR_ACCE`、`SENSOR_GYRO`、`SENSOR_MAG`、`SENSOR_HR`、`SENSOR_SPO2`、`SENSOR_LIGHT`、`SENSOR_TEMP`、`SENSOR_BARO`、`SENSOR_STEP`、`SENSOR_PROXIMITY`、`SENSOR_ECG`、`SENSOR_CAP`

LVGL 对象 API 见 [LV API](./lvgl)。句柄和回调的生命周期约束见 [SNI 与资源生命周期](./sni)。
