# JavaScript 脚本

ElenixOS 的应用和表盘可以由 JavaScript 脚本实现。脚本运行在系统提供的 JavaScript 引擎中，通过 `eos` 访问 ElenixOS 能力，通过 `lv` 创建和操作 LVGL 对象。

## 脚本包入口

脚本包至少应包含运行时要求的 `manifest.json` 和入口脚本。应用和表盘的入口文件名为 `main.js`。包的 API 兼容性由 `minApiLevel` 与 `targetApiLevel` 声明；当 `minApiLevel` 高于当前系统 API level 时，应用不会启动。

脚本包的 manifest 必须包含 `id`、`name`、`version`、`author`、`description`、`minApiLevel` 和 `targetApiLevel`。`permissions` 可声明当前实现认识的权限名：`location`、`sensor`、`notification`、`storage`、`bluetooth`、`audio`、`health`、`contacts`、`calendar`。未知权限会被忽略并记录警告。

## 运行约束

- 脚本在系统事件循环中执行；不要在回调中执行长时间同步工作或阻塞等待。
- 当前脚本上下文只提供 `eos` 和 `lv` 两个系统 API 命名空间。
- JS 可见的 LVGL/ElenixOS 对象是受运行时管理的句柄。所属 Activity、View 或原生对象销毁后，原句柄不能继续使用。
- 脚本异常、解析失败、模块链接失败、无响应和引擎崩溃会由运行时归类处理；不要依赖某个旧版内部错误常量作为应用接口。
- `eos.console.*` 和 LVGL 回调应尽快返回。需要延后处理时，使用 LVGL timer 或其他已提供的事件机制。

## 生命周期

脚本应用在启动时创建运行上下文并执行入口；切换到其他页面时应用可以被挂起，回到应用时恢复同一上下文。Recent Apps 会保留受限数量的挂起应用；达到内存水位或数量上限时，最久未使用的应用会被完整停止并释放其上下文。

脚本表盘作为根 Activity 运行。打开应用时表盘暂停，返回表盘时恢复；切换表盘、卸载表盘或引擎复位时，旧表盘会被销毁。
