# LVGL 界面接口

脚本通过 `lv` 使用当前运行时注册的 LVGL 类。对象构造函数接收父对象；页面根对象通常来自 `eos.view.active()`。

```js
const view = eos.view.active();
const button = new lv.button(view);
button.setSize(180, 64);
button.align(lv.ALIGN_CENTER, 0, 0);

const label = new lv.label(button);
label.setText("Hello, ElenixOS!");
label.center();
```

## 当前导出的类

当前运行时注册的类为：`obj`、`button`、`label`、`arc`、`bar`、`screen`、`color`、`timer`、`anim`、`buttonmatrix`、`calendar`、`chart`、`canvas`、`checkbox`、`dropdown`、`image` 和 `imagebutton`。其中 `screen`、`color` 是静态工具类，`obj`、控件类、`timer` 和 `anim` 按各自构造函数使用。

完整 LVGL 文档中的类名不自动构成 ElenixOS JS API；脚本仅可使用已注册的类。具体方法和属性以当前页面及绑定为准。

## 对象、布局和样式

通用对象提供位置、尺寸、对齐、父子关系、标志、事件和删除等操作；例如 `setPos`、`setSize`、`align`、`setFlexFlow`、`addFlag`、`addEventCb` 和 `delete`。控件再提供自己的属性，例如 `label.setText` 或 `bar.setValue`。

```js
const panel = new lv.obj(view);
panel.setSize(300, 100);
panel.setFlexFlow(lv.FLEX_FLOW_ROW);
panel.setStyleBgColor(lv.color.hex(0x202020), 0);
```

颜色工具的实际入口是 `lv.color.hex(number)`。布局常量、方向、事件、样式和控件常量以 `lv` 根常量形式导出，但可用常量集合来自当前绑定，而不是原生 LVGL 的全部宏。

## 事件

```js
button.addEventCb((event) => {
    eos.console.log("Button clicked");
}, lv.EVENT_CLICKED, null);
```

对象还提供 `removeEventCb`、`removeEventCbWithUserData` 和 `sendEvent`。事件回调在 LVGL 运行时上下文同步执行，阻塞会延迟该上下文中的其他工作。控件或父对象删除后，相关回调和脚本句柄随之失效。

## 资源生命周期

脚本创建的对象通常随父对象树管理；`timer` 和 `anim` 是独立脚本资源。Activity/View 销毁、程序停止或引擎复位时，相关资源会被运行时清理。脚本应在不再需要时使用对象提供的删除接口，并始终避免保存已经删除的句柄。
