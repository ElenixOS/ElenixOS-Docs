# 硬件层

硬件层是设备驱动实际控制的显示、输入、传感器、存储、音频和电源硬件。ElenixOS 的上层 API 不直接描述某一块具体芯片；平台通过驱动和设备操作表提供可用能力。

当前模拟器没有物理手表硬件：Native 使用 SDL2 模拟显示和输入，WASM 使用浏览器画布、HTML 控件和虚拟文件系统。模拟器中展示的 390×450 显示区域是当前平台配置，不是所有硬件产品的通用规格。

真实硬件移植需要为支持的设备实现相应操作并在服务初始化前注册。未实现的设备能力应保持不可用并由服务返回错误或能力状态；上层不能根据硬件层的预期设计假定功能存在。
