# UI 组件模块

ElenixOS 的 UI 建立在 LVGL 上。系统框架提供 Activity/View、应用头部、动画和若干可复用控件；脚本则通过 `lv` 访问已经注册的 LVGL 类。

## 使用边界

Activity 拥有页面 View。父对象删除可能级联删除子对象，页面和组件在删除后不能继续使用原 LVGL 指针或脚本句柄。由 Activity、Recent Apps 或系统 overlay 管理的对象，应通过所属管理器的生命周期接口处理，而不是直接删除其根对象。

动画和事件回调运行在 LVGL 主循环上下文中，回调不应阻塞。需要延迟或重复执行的工作可使用 LVGL timer。

## 当前 C 组件

当前 UI 目录中的可复用组件包括基础控件、Activity 应用头部、Panel、Toast、消息列表、CardPager、Slide Widget、Swipe Panel、Bubble Grid、Numpad、加载指示器和表盘专用组件。每个组件的公开创建、配置、回调和删除接口以其页面及当前头文件为准；组件名称不意味着所有组件都可从 JS 使用。

## 脚本 UI

脚本使用 `new lv.<class>(parent)` 创建可构造控件，使用 `eos.view.active()` 取得当前 View；部分静态类和表盘组件通过 `eos` 提供。当前实际导出的类以 [LV API](../script_engine/lvgl) 和 [ElenixOS JS API](../script_engine/elenix_os) 为准。
