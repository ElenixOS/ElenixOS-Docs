# Swipe Panel

Swipe Panel 是基于 Slide Widget 的边缘滑动面板，支持上、下、左、右四个方向。创建后，面板可由手势或 API 显示、隐藏和移动。

```c
eos_swipe_panel_t *sp = eos_swipe_panel_create(parent);
eos_swipe_panel_set_dir(sp, EOS_SWIPE_DIR_DOWN);
eos_swipe_panel_show(sp);
eos_swipe_panel_pull_back(sp);
eos_swipe_panel_hide_handle_bar(sp);
eos_swipe_panel_delete(sp);
```

方向常量为 `EOS_SWIPE_DIR_UP`、`EOS_SWIPE_DIR_DOWN`、`EOS_SWIPE_DIR_LEFT` 和 `EOS_SWIPE_DIR_RIGHT`。`eos_swipe_panel_move(sp, target, anim)` 使用显示坐标轴上的绝对坐标；`anim` 为真时执行动画。

组件包含面板对象、手势区域和 handle bar。默认手势区域为 50 像素，默认动画由组件内部选择；调用者不应依赖内部对象布局。需要监听滑动状态时，使用其内部 Slide Widget 的公开回调注册接口。
