# Slide Widget

Slide Widget 是一个水平或垂直滑动控制器。它让目标对象跟随触摸对象移动，并在释放时根据阈值自动打开或回到基准位置。

## 创建与控制

```c
eos_slide_widget_t *sw = eos_slide_widget_create(
    parent, target_obj, EOS_SLIDE_DIR_HOR, 100, EOS_THRESHOLD_50);

eos_slide_widget_move(sw, 0, 100, 200);
eos_slide_widget_set_bidirectional(sw, true);
eos_slide_widget_reverse(sw);
eos_slide_widget_delete(sw);
```

如果已有触摸对象，使用 `eos_slide_widget_create_with_touch`。`target` 是目标对象在所选轴上的目标坐标；阈值使用 0–255 标度的 `EOS_THRESHOLD_0` 至 `EOS_THRESHOLD_100`，`EOS_THRESHOLD_INFINITE` 可禁用阈值触发。

不要再对由 Slide Widget 控制的目标对象调用 `lv_obj_center`，否则会与它维护的坐标范围冲突。

## 状态与回调

状态包括 `IDLE`、`DRAGGING`、`THRESHOLD`、`REVERTING`、`ANIMATING` 和 `OPEN`。可以读取状态、位移、当前位置、基准/目标位置、方向和触摸/目标对象。

回调通过组件提供的注册函数绑定，而不是通过事件总线：

```c
eos_slide_widget_add_event_cb_reached_threshold(sw, cb, user_data);
eos_slide_widget_add_event_cb_reverted(sw, cb, user_data);
eos_slide_widget_add_event_cb_moving(sw, cb, user_data);
eos_slide_widget_add_event_cb_done(sw, cb, user_data);
eos_slide_widget_add_event_cb_opened(sw, cb, user_data);
eos_slide_widget_add_event_cb_closed(sw, cb, user_data);
```

回调接收 LVGL 事件对象，触摸对象是事件目标。组件创建前由系统初始化事件类型；应用不应假设这些事件 ID 是固定的全局常量。
