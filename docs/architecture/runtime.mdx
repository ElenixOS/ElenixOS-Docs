# 运行时

ElenixOS 运行时负责初始化系统服务、驱动当前 Activity、执行脚本，并在页面和程序切换时协调资源生命周期。

## 初始化顺序

模拟器启动后先初始化 LVGL 和平台设备，再初始化显示、电源、时间、电池、音频、传感器和振动等服务，最后启动 ElenixOS 的应用/表盘运行时。具体设备是否可用取决于平台实现；服务调用应检查返回结果或能力状态。

## 程序与页面

脚本程序、Activity 和 View 是不同层次的对象：程序拥有 JavaScript 上下文，Activity 管理页面生命周期，View 是 LVGL 对象树中的页面根对象。切换页面时，Activity 负责暂停/恢复；停止程序时，程序上下文和其脚本资源一起清理。

脚本应用支持挂起和恢复。挂起不会等同于引擎销毁：程序上下文可以保留，Recent Apps 也会保留被挂起应用的页面快照。应用被驱逐、卸载、切换到其他应用或发生致命引擎错误时，才会进入完整停止/清理流程。

## 脚本资源边界

`lv` 和 `eos` 返回的对象句柄不能脱离其所属脚本上下文和原生对象使用。Activity/View 被销毁后，保存的句柄必须视为失效。由 Activity 管理的对象不应由脚本或其他模块绕过所属管理器直接删除。

脚本回调在运行时主循环中调用。回调应避免阻塞；需要重复执行的工作应拆分到 timer 或事件回调中。

## 错误与复位

运行时会区分脚本异常、解析失败、模块链接失败、无响应和引擎崩溃。引擎致命错误会发布 `EOS_EVENT_SCRIPT_FATAL`，并重置脚本运行环境；受影响程序的脚本资源不能继续使用。错误显示和日志输出属于系统 UI/日志层，脚本不应假定所有错误都能恢复到原页面。
