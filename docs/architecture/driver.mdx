# 驱动层

驱动层是平台与 ElenixOS 设备抽象之间的适配边界。驱动实现设备公开的操作表，在系统初始化阶段注册，并在设备状态或传感器数据变化时向设备/服务层报告。

## 操作边界

驱动只实现当前平台能提供的设备操作；业务策略由服务处理。例如显示驱动提供亮度和电源操作，传感器驱动提供采样/启停并提交原始数据，音频驱动提供播放端口和麦克风捕获端口。

设备类型的操作表并不完全相同，不能假设存在一个适用于所有驱动的通用 `register`、`read` 或 `deinit` 函数。注册失败、设备不可用和操作失败应按各接口的返回值处理。

## 输入与异步数据

触摸、表冠和侧边按钮由平台输入适配层提交给系统输入模块。传感器驱动使用 `eos_sensor_notify()` 向传感器服务提交数据；应用回调不应由驱动直接调用。

Native 和 WASM 模拟器分别使用 SDL2 与浏览器/Emscripten 平台实现。驱动文档描述的是适配边界，不承诺某个模拟平台具备真实硬件能力。
