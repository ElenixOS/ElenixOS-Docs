# Activity

Activity 是 ElenixOS 的页面生命周期和页面切换抽象。一个 Activity 通常对应一个 View，并通过生命周期回调创建、暂停、恢复和销毁页面内容。

## Activity 类型

当前定义的类型包括：

| 类型 | 用途 |
|---|---|
| `EOS_ACTIVITY_TYPE_NULL` | 未分类页面 |
| `EOS_ACTIVITY_TYPE_APP` | 应用页面 |
| `EOS_ACTIVITY_TYPE_INPUT_PAGE` | 输入页面 |
| `EOS_ACTIVITY_TYPE_APP_LIST` | 应用列表 |
| `EOS_ACTIVITY_TYPE_WATCHFACE` | 当前表盘 |
| `EOS_ACTIVITY_TYPE_WATCHFACE_LIST` | 表盘列表 |
| `EOS_ACTIVITY_TYPE_LOCK_SCREEN` | 锁屏 |
| `EOS_ACTIVITY_TYPE_RECENT_APPS` | Recent Apps 页面 |

## 根 Activity 与页面栈

系统始终有一个根 Activity，通常是当前表盘。根 Activity 独立于普通页面栈管理，`eos_activity_back()` 不会销毁它。应用和系统页面可以压入栈中，返回时销毁当前栈页面；切换到新页面时，当前页面会暂停，返回时再恢复。

根 Activity 应使用 `eos_activity_create_root()` 创建。它会立即创建 View；普通 `eos_activity_create()` 创建的 Activity 需要在 `on_enter` 中通过生命周期逻辑设置 View。根 Activity 可由 `eos_activity_replace_root()` 替换，旧根 Activity 随替换被销毁。

## 生命周期

```c
typedef struct {
    eos_activity_on_enter_t on_enter;
    eos_activity_on_destroy_t on_destroy;
    eos_activity_on_pause_t on_pause;
    eos_activity_on_resume_t on_resume;
} eos_activity_lifecycle_t;
```

- `on_enter`：Activity 第一次进入时调用；普通 Activity 应在这里创建并设置 View。
- `on_pause`：Activity 离开当前可见状态、但仍可恢复时调用。
- `on_resume`：已暂停 Activity 再次成为活动页面时调用。
- `on_destroy`：Activity 最终销毁时调用。此后不能继续使用 Activity 或其 View。

Activity View 由 Activity 管理。`eos_activity_set_view()` 只应在 `on_enter` 中调用；不要在页面已经运行后随意替换它。删除父 View 可能连带删除子控件，因此页面保存的 LVGL 指针必须在销毁后失效化。

## 常用 C API

```c
eos_activity_t *eos_activity_create(const eos_activity_lifecycle_t *lifecycle);
eos_activity_t *eos_activity_create_root(const eos_activity_lifecycle_t *lifecycle);
void eos_activity_destroy(eos_activity_t *activity);

eos_activity_t *eos_activity_get_current(void);
eos_activity_t *eos_activity_get_visible(void);
eos_activity_t *eos_activity_get_previous(void);
eos_activity_t *eos_activity_get_bottom(void);
eos_result_t eos_activity_back(void);
eos_result_t eos_activity_back_to_watchface(void);
bool eos_activity_is_transition_in_progress(void);
```

`eos_activity_destroy()` 只适用于不在页面栈中且不可见的 Activity。当前页面应使用返回或所属管理器提供的销毁流程；对栈中/可见 Activity 直接调用该函数是不安全的。

页面标题、类型和应用头部可分别通过 `eos_activity_set_title*`、`eos_activity_set_type` 与 `eos_activity_set_app_header_visible*` 管理。默认页面切换时长由 `EOS_VIEW_SWITCH_DURATION` 定义为 300 ms，但自定义动画路由可以改变具体过渡效果。

## 页面切换事件

Activity 切换完成后会发布 `EOS_EVENT_ACTIVITY_SCREEN_SWITCHED`。这是全局事件；订阅者在回调中可通过 `eos_event_get_param(e)` 取得当前 Activity View：

```c
static void on_switched(eos_event_t *e)
{
    lv_obj_t *view = eos_event_get_param(e);
    (void)view;
}

eos_event_subscribe(EOS_EVENT_ACTIVITY_SCREEN_SWITCHED, on_switched, NULL);
```

事件回调是同步执行的，不能在其中长时间阻塞。详见[事件总线](../../kernel/event/events)。
