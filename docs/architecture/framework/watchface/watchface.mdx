# Watchface 表盘系统

表盘是系统的根页面。当前实现支持内建表盘和 JavaScript 表盘两类：内建表盘由系统直接实现，JS 表盘由脚本包驱动。两类表盘都作为根 Activity 运行，不会作为普通页面压入 Activity 栈。

## 表盘列表与回退表盘

表盘列表始终包含内建回退表盘，其 ID 为 `builtin.fallback`。它不是可安装包，不能按普通表盘卸载。已安装 JS 表盘来自表盘安装目录，默认表盘 ID 由系统配置决定，当前默认值为 `cn.sab1e.clock`。

## 切换与生命周期

```c
void eos_watchface_switch_to(const char *watchface_id);
void eos_watchface_check_and_reload(void);
```

切换表盘会替换根 Activity，并销毁旧表盘及其 View/脚本资源。打开应用时当前 JS 表盘暂停，返回表盘时可以恢复；切换表盘、卸载表盘或脚本引擎复位时旧表盘会被完整销毁。

`eos_watchface_check_and_reload()` 用于系统检查当前表盘配置是否变化并重新加载，属于系统返回根页面等流程使用的检查接口。调用 `eos_watchface_switch_to` 后应以实际当前根 Activity 为准，不要继续使用被替换的旧对象。

## JS 表盘

JS 表盘包需要符合脚本包 manifest 和 API level 约束，并使用 `main.js` 作为入口。脚本可以使用 `eos.ww` 表盘组件，以及通用 `eos` 和 `lv` API。资源路径相对于该表盘包的 `assets/` 目录。

## 表盘组件

当前 `eos.ww` 提供时间日期、电池、充电、健康、环境、指南针、环形指示器和背景等组件工厂。组件返回 LVGL 对象句柄，生命周期受其父 View 和表盘 Activity 管理；表盘切换后不能继续使用旧句柄。
