# 本地运行（Native Simulator）

Native 模拟器把 ElenixOS 编译为主机上的桌面程序，并通过 SDL2 模拟显示和输入。它不需要开发板交叉编译工具链。

## 构建

```bash
git clone --recursive https://github.com/ElenixOS/ElenixOS-Simulator.git
cd ElenixOS-Simulator
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
```

构建输出的可执行文件是仓库根目录 `bin/main`：

```bash
./bin/main
```

根目录 Makefile 也提供 `make`、`make build`、`make run` 和 `make clean` 目标。`make menuconfig` 会配置并执行 CMake 的 `menuconfig` 目标。

## 运行时交互

模拟屏幕固定为 390×450 像素。Native 窗口提供表冠和侧边按钮的模拟控件；表冠还可通过鼠标滚轮模拟编码器旋转。短按表冠和侧边按钮会产生各自的点击输入，长按表冠会产生长按输入。

窗口可调整大小，最小尺寸由模拟器设置；调整窗口大小只改变桌面显示，不改变系统显示尺寸。

## 调试与选项

Debug 构建包含调试信息。需要内存错误检测时，在 Debug 配置中加入 `-DASAN=ON`：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DASAN=ON
cmake --build build --parallel
```

FreeRTOS 模式只适用于 Native：

```bash
cmake -S . -B build -DUSE_FREERTOS=ON
cmake --build build --parallel
```

绘制后端、图片格式、FFmpeg 和 FreeType 等能力通过 CMake 选项控制；依赖缺失时相应选项不能启用。Kconfig 配置请参见[内核配置系统](../development/kconfig)。

Native 构建需要 SDL2 开发库。若配置阶段无法找到 SDL2，请检查系统开发包和 CMake 的搜索路径。
