# WASM Simulator 运行边界

WASM 模拟器通过 Emscripten 将同一套 ElenixOS 模拟器编译为浏览器页面。在线版本位于[在线模拟器](https://simulator.elenixos.com/wasm/latest/main.html)。

WASM 是浏览器中的辅助运行环境，不是 ElenixOS 设备固件目标；其浏览器文件系统、输入控件和可用设备能力受页面运行环境限制。板级构建目标见[板级固件构建路径](../getting_started/build)。

WASM 配置、构建和本地启动命令见[Simulator 构建与运行](./build)。该目标需要安装并激活 Emscripten SDK。

构建产物位于 `build-wasm/bin/`，主要包括：

- `main.html`：页面入口
- `main.js` 和 `main.wasm`：Emscripten 运行时代码
- `main.data`：预加载的数据文件（文件名可能随构建配置变化）

WASM 构建会把系统文件目录预加载到页面的虚拟文件系统中；它不会访问宿主机的任意本地路径。

浏览器中的模拟显示为 390×450 像素，页面外壳提供表冠和侧边按钮控件。WASM 版本没有 Native 的 SDL 窗口或 FreeRTOS 运行模式。

## 发布路径

仓库的 WASM 工作流会将构建结果部署到类似下面的路径：

```text
wasm/latest/main.html
wasm/latest/main.js
wasm/latest/main.wasm
wasm/latest/main.data
```

具体站点 URL 取决于部署仓库和分支；嵌入其他页面时应使用部署后的 `main.html` 绝对或相对 URL，并确保同目录的 JS、WASM、data 文件可访问。
