# 项目集成

当前公开的可运行集成以 ElenixOS-Simulator 为主。模拟器仓库包含 ElenixOS 核心、LVGL、FreeRTOS（Native 可选）和平台适配所需的构建配置。

## 获取模拟器

```bash
git clone --recursive https://github.com/ElenixOS/ElenixOS-Simulator.git
cd ElenixOS-Simulator
```

如果仓库已经存在：

```bash
git submodule update --init --recursive
```

递归克隆是必要的，因为核心和图形库以子模块/仓库依赖参与构建；只克隆外层目录不能保证源码完整。

## 构建平台

Native 使用主机 SDL2 构建为 `bin/main`；WASM 使用激活的 Emscripten 工具链构建到 `build-wasm/bin/`。完整命令见[构建与使用](../getting_started/build)、[Native](../simulator/native)和[WASM](../simulator/wasm)。

## 应用集成边界

应用和表盘通过统一的 `.epk` 包、EPK Header Package Type、manifest、`main.js`、`eos` 和 `lv` API 集成。Application/Watch Face 类型不应依赖文件名或 manifest 重复字段。它们不应依赖模拟器的内部源文件路径、裸设备接口或未挂载的 JS 类。需要平台设备能力时，应通过服务 API 并处理设备不可用/接口返回错误的情况。
